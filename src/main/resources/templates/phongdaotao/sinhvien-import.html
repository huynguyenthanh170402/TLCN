Các dòng bị bỏ qua:
Các dòng hợp lệ đã được lưu. Sửa những dòng trên rồi nhập lại file chỉ chứa các dòng đó.
1. Tải file mẫu

File mẫu có sẵn dòng tiêu đề và một dòng ví dụ. Xóa dòng ví dụ rồi điền danh sách thật.

Tải file Excel mẫu
Thứ tự cột:
  1. MSSV *
  2. Họ tên *
  3. Ngày sinh (dd/MM/yyyy)
  4. Giới tính (Nam / Nữ)
  5. Tên ngành *
  6. Khóa tuyển sinh
  7. Email trường
  8. Số điện thoại
Tên ngành phải trùng khớp với ngành đang có trong hệ thống. Dữ liệu bắt đầu từ dòng 2.
2. Tải file danh sách lên
Hệ thống sẽ tự động:
  • Tạo tài khoản đăng nhập cho từng sinh viên, tên đăng nhập là MSSV, mật khẩu
  • Bỏ qua dòng trùng MSSV, thiếu dữ liệu bắt buộc hoặc sai tên ngành, rồi liệt kê ra cho bạn sửa
  • Đặt trạng thái sinh viên là Đang học
